# Виртуальный музей «Россия в эпоху мировых войн»
Статический сайт (HTML, CSS, JavaScript). Сервер и установка программ не нужны.

## Публикация на GitHub Pages
GitHub Pages бесплатно публикует статические сайты. Ваш компьютер после публикации можно выключить.
1. Зайдите на github.com, нажмите **New repository**, назовите его, например, `museum`, выберите **Public**, нажмите **Create repository**.
2. Нажмите **uploading an existing file**, перетащите **содержимое** папки museum (index.html, style.css, script.js, папку images), нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В разделе **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты вверху страницы Pages появится ссылка вида `https://ваш-логин.github.io/museum/`.
5. Откройте эту ссылку в браузере телефона (Safari или Chrome).
6. Отправьте ссылку одноклассникам в мессенджере или покажите QR-код.

## Фотографии
Сайт сам ищет файлы в папке `images/`: `hero.jpg` (фон главной) и `w1-1.jpg … w1-8.jpg`, `w2-1.jpg … w2-9.jpg` (по порядку событий). Если файла нет, показывается красивая заглушка с годом. Берите свободные фотографии на commons.wikimedia.org (проверьте лицензию) и укажите источники в конце проекта или на уроке. Файлы лучше сжать до 200–300 КБ.
